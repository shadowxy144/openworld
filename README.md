## 🇹🇷 Türkçe

Bu araç, yerel bir dizindeki web içeriğini hızlıca `cloudflared` tüneli kullanarak dış dünyaya (internete) açmanızı sağlayan basit bir bash scriptidir.

### Özellikler
- **Hızlı Kurulum:** Cloudflare resmi deposunu otomatik ekler ve `cloudflared` kurulumunu yapar.
- **Güvenli ve Sessiz:** Arka planda (`background`) çalışır, terminalinizi kirletmez.
- **Kullanımı Kolay:** Menü tabanlı basit arayüz.
- **Güvenli Kapatma:** Tüneli ve yerel sunucuyu otomatik temizler.

### Kurulum ve Kullanım
1. Scriptin olduğu dizine gidin.
2. Çalıştırma izni verin:
   ```bash
   chmod +x menu.sh**
